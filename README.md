# No Sweat
This is a  "Choose Your Own Adventure" game made with HTML, CSS, and JS, otherwise known as a web browser game. I personally love zombies and story games, so making this was an obvious choice to get started with game development. Essentially, you wake up in the middle of the night during the zombie apocalypse and must survive the night without dying. 

# How to Play
Playing this game is extremely simple. You read the prompt given and choose a button showing a decision. Different decisions will lead to different paths and outcomes, though a few main events will remain the same. 
You can try out the game in your browser as I make progress here: (https://cooly-kirbyy.github.io/NoSweat/)
